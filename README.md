# Smart Deal

Smart Deal is a local shopping price-discovery app starting in Tiruchirappalli (Trichy).

## Current MVP

- Browse everyday product categories
- Search products, categories, and demo shops
- View sample product prices
- Shop-owner registration contact section

> Product prices and shop names currently shown in the UI are demo data. Replace them with verified shop-owner updates before launch.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.
